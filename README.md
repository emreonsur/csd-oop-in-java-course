# Object-Oriented Programming in Java Course

This repository is a personal fork of [C & System Programmers Association (CSD)](https://csystem.org/)'s _Object-Oriented Programming in Java_ course [original repository](https://github.com/oguzkaran/Java-Jan-2024).

My primary goal is to add my own insights and annotations to the existing notes while studying and practicing the course material, which I consider an invaluable resource for learning core Java.

**Note on language:** The course material is in Turkish. Over time, I may translate parts of the content into English to reinforce my own understanding and to provide a helpful resource for other CSD students.
